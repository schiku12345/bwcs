Quick Setup
1
Edit config/config.js
Add your maps, phase icons, point rules, and (optionally) a Firebase config for cross-computer sync and an admin password.
2
Open the Admin Panel
Click Admin Panel above. Go to Theme & Config → Load config.js to apply your settings, then add teams in the Teams tab.
3
Add OBS Browser Source
In OBS add a Browser Source at 1920×1080. Use the overlay URL from the admin Dashboard. Enable Refresh browser when scene becomes active.
4
GitHub Pages (optional)
Push the repo to GitHub, enable Pages via Settings → Pages → GitHub Actions. Your admin and overlay are then accessible from any browser on any machine.
